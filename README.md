# Matplotlib Fundamentals

A complete, structured practice repository covering Matplotlib data visualization — from basic plots to advanced styling and annotations.

---

## 📌 About This Repository

This repository covers all essential Matplotlib chart types with real examples and proper styling. Data visualization is a critical skill in Machine Learning and Data Science — understanding how to present data visually is as important as building models.

---

## 📁 Repository Structure

```
matplotlib-fundamentals/
│
├── plots/
│   ├── 01_bar_chart.py         # Single and grouped bar charts
│   ├── 02_box_plot.py          # Box plots for statistical distribution
│   ├── 03_fill_between.py      # Fill area under line charts
│   ├── 04_histogram.py         # Histograms with custom bins
│   ├── 05_pie_chart.py         # Pie charts with explode and styling
│   ├── 06_scatter_plot.py      # Scatter plots with colormap
│   ├── 07_stack_plot.py        # Stacked area charts
│   ├── 08_stem_plot.py         # Stem plots for discrete data
│   ├── 09_step_plot.py         # Step function plots
│   ├── 10_subplots.py          # Multiple charts in one figure
│   ├── 11_text_annotations.py  # Text, labels and arrows on charts
│   └── 12_save_figure.py       # Export charts as image files
│
├── .gitignore
├── requirements.txt
└── README.md
```

## 🧠 Topics Covered

| # | Plot Type | Key Concepts |
|---|-----------|-------------|
| 01 | Bar Chart | Single bar, grouped bar, width, color, edgecolor |
| 02 | Box Plot | IQR, outliers, whiskers, multiple groups |
| 03 | Fill Between | Shade area under curve with condition |
| 04 | Histogram | Bins, frequency, axvline, grid |
| 05 | Pie Chart | Labels, explode, autopct, shadow, colors |
| 06 | Scatter Plot | Colormap, colorbar, marker, multi-series |
| 07 | Stack Plot | Stacked areas, alpha, legend |
| 08 | Stem Plot | Discrete data, markerfmt, basefmt |
| 09 | Step Plot | Step function, grid, markers |
| 10 | Subplots | fig, axes, 2x2 grid layout |
| 11 | Text & Annotations | text(), annotate(), arrowprops, bbox |
| 12 | Save Figure | savefig(), dpi, bbox_inches |

## 🚀 How to Run

**1. Clone the repository:**
```bash
git clone https://github.com/Arifkhan171/matplotlib-fundamentals.git
cd matplotlib-fundamentals
```

**2. Install dependencies:**
```bash
pip install -r requirements.txt
```

**3. Run any plot:**
```bash
python plots/01_bar_chart.py
python plots/04_histogram.py
```
